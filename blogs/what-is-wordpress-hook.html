What is Wordpress Hook.

Publish on 20 Sep 2018 by Brooks
Wordpress Development

What is Wordpress Hook?

Wordpress hook is simply a place(s) in your code where you can change the default functionality. The best thing about using hooks is that the core functionality will not be overwritten, but you are still given the option to customize your wordpress functionality to your best need. Although you can create custom hooks, by default there are 2 types of hooks in Wordpress. Actions hooks and filter hooks.

Action Hooks?

Action hooks are basically what it sounds like. It allows you to complete a certain action when an event happens. For example you want to add a custom popup alert every time you save a blog post. This functionality could be added using an action hook. So you can basically write a function and use the add_action() function to hook it into wordpress. You can also find a list of all Wordpress hooks online at developer.wordpress.org

add_action(‘save_post’, ‘yourfunctionhere’);
add_action( string $hook_name, callable $callback, int $priority = 10, int $accepted_args = 1 );

Filter Hooks

Allows you to modify data before it’s stored or modified. For example you want to add the word “space” everywhere the word “office” is found on you site. You can do this using the filter hook. Similar to the action hook, you can basically write a function and use the add_filter() function to hook it into wordpress. You can also find a list of all Wordpress hooks online at developer.wordpress.org
